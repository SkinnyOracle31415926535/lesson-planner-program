# ADR-008: Keep v1 focused on planning and coaching

**Status:** Accepted — 2026-07-18

## Context

The owner values reduced planning work and intentional organization more than an expansive system that is difficult to use.

## Decision

Exclude in-app conversational AI, freehand Pencil drawing, public/team sharing, external attendance posting, and automatic schedule booking from v1. Use deterministic smart suggestions, editable visual objects, private access, and advisory schedule information instead.

## Consequences

- The first release can concentrate on reliable schedule-aware planning, retrieval, local media, and in-class use.
- Later requests in excluded areas should be treated as deliberate new ADRs rather than quietly added scope.
