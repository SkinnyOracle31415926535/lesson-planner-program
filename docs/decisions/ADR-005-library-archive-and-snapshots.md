# ADR-005: Active Shelf, archive, and immutable lesson snapshots

**Status:** Accepted — 2026-07-18

## Context

The owner wants to save every idea but avoid losing the best material in an enormous drill board. Existing drill families have variants, source images, and mixed testing states.

## Decision

Import everything with provenance. Use Inbox, Active Shelf, and Archive; only explicit stars/pins promote gems. Rank relevance with completed-lesson history, not abandoned drafts. Add selected drill variants and phase recipes as editable lesson snapshots whose later source edits affect future use only.

## Consequences

- Historical content remains retrievable without cluttering planning.
- Card/recipe changes cannot silently rewrite plans already drafted, Ready, completed, or archived.
- Source/provenance remains available in a drawer rather than dominating ordinary cards.
