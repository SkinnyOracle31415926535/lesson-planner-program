# ADR-007: Daily operations stay coach-controlled

**Status:** Accepted — 2026-07-18

## Context

The coach needs recurring/temporary work, daily crawl updates, announcements, safety context, attendance, and quick post-class learning without creating more paperwork.

## Decision

Allow tasks scoped by class/phase/lesson; recurring tasks repeat and temporary tasks roll forward until completed. Show crawl updates on first daily open, require manual conversion of important updates, reject only the current source revision, require safety checklist acknowledgment before Ready, and record attendance only inside the app/export. Completion offers a short optional reflection.

## Consequences

- No email login, automatic announcement, or Jackrabbit posting in v1.
- Important operational context stays visible but never silently edits the lesson.
- Completed lessons, not draft placement, drive recently-used ranking.
